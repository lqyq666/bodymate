## 可直接用于申报的内容

**项目名称**

BodyMate —— 基于 MoonBit 的全身教学动作引擎与交互实验室

**项目类别**

新项目；原创应用与内容工具／图形与通用内容处理组件。动作库与人体网页作为同一个项目申报。

**项目简介**

BodyMate 为人体教学和参数化动作工具提供一个可复用的 MoonBit 动作领域库，并通过完整人体交互网页展示实际用途。库负责动作参数与单位约束、中文参数解析、独立播放会话、定性参与提示和确定性姿态目标；其他 MoonBit 项目可以直接导入使用，无需 DOM、Three.js、人体模型或 npm 包。网页使用同一份核心驱动 415 条肌肉、282 个骨骼及相关结构的教学模型，提供俯卧撑、深蹲、弯举、参数调整、暂停、进度、速度、中文选肌与独立人体参照。

**目标用户与通用性**

开发离线人体教学、动作演示、参数化交互工具的开发者，以及需要观察结构与动作协同的学习者。参数规则、解析、独立会话与数据输出可被不同 MoonBit 消费者复用；姿态采样当前绑定 BodyMate 的固定教学骨架，采用其他骨架需要适配尺寸与坐标约定。

**核心功能与边界**

1. 有界中英文动作识别、参数范围、预设、步进取整及错误提示。
2. 无全局状态的独立 Session，支持 play/stop/reset、暂停、速度、seek 与 elapsed-time tick。
3. 类型化 PoseIntent，支持无界面重复采样；非有限输入有明确退化策略。
4. 完整人体网页作为真实消费示例，展示参数变化确实影响姿态。
5. 包含公开接口、黑盒测试、三个示例、实际发布包隔离复现及 CI。

不承诺通用骨骼重定向、BVH 导入、任意动作生成、生物力学、肌电、诊断或训练处方。颜色和 profile 权重仅用于教学视觉强调。

**公开仓库**

https://github.com/lqyq666/bodymate

## 至少三个完整应用场景

| 场景 | 用户输入 | 核心处理 | 可运行输出与验收 |
| --- | --- | --- | --- |
| 1. 教学工具的中文动作参数入口 | 深蹲“宽站距，脚尖外展25度，深度80%”；俯卧撑手距 9 | MoonBit 识别预设与单位，限制范围并输出提示 | 站距 1.8、脚尖角 25、深度 80；越界手距回 1.8。运行 `moon run moonbit/examples/parameters --target js`，断言通过并输出 PASS |
| 2. 两个消费者独立观察动作 | 创建深蹲与弯举两个 Session；分别推进、暂停、reset | MoonBit 实例隔离、暂停/速度/相位状态机，返回分离快照 | 深蹲 2.2 秒相位 0.5；暂停或 reset 不改变另一会话。运行 `moon run moonbit/examples/sessions --target js` |
| 3. 无界面生成可重复姿态帧 | 深蹲深度 80%，相位 0、0.25、0.5、0.75、1 | MoonBit 规范化并求姿态目标，不加载渲染器 | 返回五帧标量；相位 0.5 的 excursion=0.8，同输入重复采样相等。运行 `moon run moonbit/examples/sampling --target js` |

三者都是真正调用公开库 API 的独立 MoonBit 可执行包。`npm run moonbit:package-check` 进一步证明实际发布 ZIP 在没有应用资源的目录中仍能运行这些场景。

## MoonBit 主要实现语言的证据

- 可复用动作组件的全部领域实现与三个示例为 MoonBit；无 JS 业务替身，也不依靠包装已有 JS 动作库运行。
- 页面 V1 接口仅调用该库并序列化；保留浏览器兼容性，不复制参数、预设或会话规则。
- JS/Three.js 负责资源、几何 IK、渲染、相机、材质、中文肌肉索引及界面；这些职责如实列出。
- `npm run moonbit:stats` 分开报告可复用库、全身策略、适配器、保留颈肩契约和示例。不用 GLB、生成 JS、注释或旧功能堆成“核心行数”。
- “以 MoonBit 为主”最终由赛事组结合项目整体认定，不能用一个自定行数或百分比替代审核。
