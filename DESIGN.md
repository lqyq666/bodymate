# BodyMate Design System

## Overview

BodyMate is a desktop-first anatomy exploration interface. Cool white and blue surfaces suggest a well-lit research studio, while blue is reserved for the selected structure and primary action.

## Color

- Ink: `#203657`
- Muted text: `#8392A9`
- Primary blue: `#2583F4`
- Background: `#EAF0F8`
- Surface: translucent white over the cool background

## Typography

Use the system-friendly Inter / Segoe UI / PingFang SC / Microsoft YaHei sans-serif stack. Maintain a compact product scale and favor direct labels over marketing copy.

## Layout

At desktop width: narrow utility rail, full-body navigator, flexible detail view, and an action sidebar. On mobile, arrange navigation and local view above the current action area so the input remains stable while interacting with the model.

## Interaction

Use blue for active selection and primary action. Transitions communicate changes of selection, isolation, or disclosure; respect `prefers-reduced-motion` by disabling the pulse.
